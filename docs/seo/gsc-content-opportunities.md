## Publishing rule

Before creating any item above:

1. Re-check current Search Console queries.
2. Search the repository for an existing equivalent page.
3. Define a unique primary intent and parent cluster.
4. Add reciprocal internal links.
5. Avoid publishing if the new page would simply restate an existing article.

Teacher skills, student summary, student no-experience, the homepage, `/fr/`, Resume Templates and CV Maroc should receive ranking support before broad content expansion.
